# Pastel Bloom 🌸

Pastel Bloom is an aesthetic flower bouquet website featuring customizable bouquets, wishlist functionality, and responsive UI with a smooth shopping experience.

## Features
- Responsive UI
- Bouquet customization
- Wishlist functionality
- Admin dashboard
- Backend integration
- MongoDB database support

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB

## Project Structure

```bash
frontend/   # User interface and client-side code
backend/    # Server-side logic and database integration
```
